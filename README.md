# Text to Image Generator 🎨

An AI-powered web application built with Streamlit that converts descriptive text prompts into generated images using Pollinations AI.

## Features
- Generates images directly from natural language prompts.
- Simple, interactive web user interface built with Streamlit.
- In-browser image preview and display.
